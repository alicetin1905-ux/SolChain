How this is worked out

Dexscreener's own Top Traders tab is not available through its public API, so this site rebuilds it from the chain. A GitHub Action reruns the collector once a day and commits fresh data.

  • Pairs. Token lists and prices come from Dexscreener's public API. Each token's deepest SOL, USDC or USDT pair is used.
  • Swaps. The latest transactions on each pair's pool account are read from Solana RPC. A swap is a transaction where the signing wallet's token balance and its SOL, USDC or USDT balance move in opposite directions, valued in dollars at the current SOL price. Network fees and refundable token-account rent are left out. Swaps routed through another token and swaps under $1 are skipped.
  • PnL. Sells received minus buys paid, plus the net tokens bought in the window valued at the price when the snapshot was taken. A wallet that sold tokens it bought before the window is credited for selling above that price.
  • Bot-like. A wallet is flagged when it bought and sold the same token in one slot (a sandwich pattern) or made 40 or more trades in the window. These wallets are hidden by default and get no rank.
  • Window. Each pair contributes its latest transactions. Hot pairs fill that in minutes, so this is a short-term snapshot, not a 24-hour or all-time ranking.
Data: Dexscreener public API, GeckoTerminal, Solana RPC. Not financial advice.
